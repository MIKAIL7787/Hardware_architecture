## 1. CPU

**Процессор (CPU)** - центральное устройство компьютера, которое выполняет арифметические и логические операции, а также управляет работой всех остальных компонентов. Основные характеристики: тактовая частота, разрядность, архитектура (CISC/RISC).

---

## 2. Устройство процессора

### 2.1 Основные блоки

- **Устройство управления (УУ)** - управляет работой всех блоков процессора, формирует сигналы управления, выбирает команды из памяти и организует их выполнение.
- **Арифметико-логическое устройство (АЛУ)** - выполняет арифметические (сложение, вычитание, умножение, деление) и логические (И, ИЛИ, НЕ, сравнение) операции.
- **Регистры** - сверхбыстрая внутренняя память процессора:
  - **Регистр команд (PC / IP)** - хранит адрес следующей команды.
  - **Регистр состояния (PSW / флаги)** - хранит признаки результата (нуль, перенос, знак и т.д.).
  - **Регистры общего назначения (РОН)** - для временного хранения данных.
  - **Регистр адреса и регистр данных** - для обмена с памятью.
- **Кэш-память** - быстрая память внутри процессора для ускорения доступа к данным и командам (уровни L1, L2, L3).
- **Счётчик команд** - хранит адрес следующей команды (часто совмещён с PC).
- **Блок предсказания переходов** - ускоряет выполнение за счёт предугадывания ветвлений.

### 2.2 Взаимодействие с памятью

Процессор общается с оперативной памятью через **шины**:
- **Шина данных** - передаёт данные.
- **Шина адреса** - передаёт адреса ячеек памяти.
- **Шина управления** - передаёт сигналы (чтение/запись, прерывания, тактирование).

## 3. Цикл выполнения команд

Процессор работает циклически. Каждая команда проходит несколько этапов - **цикл выполнения команды** (instruction cycle).

### Этапы цикла

1. **Выборка команды (Fetch)**  
   По адресу из счётчика команд (PC) процессор читает команду из памяти в регистр команд. Счётчик увеличивается на длину команды.

2. **Декодирование (Decode)**  
   УУ расшифровывает команду: определяет операцию (что делать) и операнды (с чем делать).

3. **Выборка операндов (Execute - подготовка)**  
   Если операнды находятся в памяти, процессор читает их в регистры.

4. **Выполнение (Execute)**  
   АЛУ или другой блок выполняет операцию; результат сохраняется в регистр или память.

5. **Запись результата (Write-back)**  
   Результат записывается в регистр или оперативную память. Обновляется регистр состояния (флаги).

6. **Проверка прерываний (Interrupt check)**  
   Процессор проверяет наличие запросов на прерывание. Если есть - обрабатывает их, затем переходит к следующей команде.

### схема цикла

```
[Начало]
   │
   ▼
[Выборка команды (Fetch)]
   │
   ▼
[Декодирование (Decode)]
   │
   ▼
[Выборка операндов]
   │
   ▼
[Выполнение (Execute)]
   │
   ▼
[Запись результата (Write-back)]
   │
   ▼
[Есть прерывание?] --Да--> [Обработка прерывания] --┐
   │Нет                                            │
   ▼                                               │
[Переход к следующей команде] <────────────────────┘
   │
   └──► (повтор цикла)
```

## 4. Конвейер команд

Современные процессоры выполняют несколько команд одновременно за счёт **конвейера** (pipeline): пока одна команда выполняется, следующая уже декодируется, а третья - выбирается. Это ускоряет работу, хотя возможны **конфликты** (зависимости по данным, ветвления).
