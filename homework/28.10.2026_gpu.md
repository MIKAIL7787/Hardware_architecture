# Часть 1

**1.**
- **GPU (графический процессор)** - выполняет вычисления: шейдеры, растеризацию, обработку вершин и пикселей.
- **VRAM (видеопамять)** - хранит текстуры, буферы кадра, шейдерные данные; быстрый доступ GPU.
- **Шина памяти** - канал обмена данными между GPU и VRAM (широкая, высокоскоростная).
- **Подсистема питания (VRM)** - преобразует питание от БП в нужные напряжения для GPU и памяти.
- **Система охлаждения** - отводит тепло от GPU, памяти и VRM (радиаторы, вентиляторы, тепловые трубки).

**2.**
- **Число ядер и их сложность:** CPU - несколько мощных ядер с развитым управлением (branch prediction, кэш); GPU - тысячи простых ядер. CPU выгоден для последовательных, ветвящихся задач (ОС, логика); GPU - для массово-параллельных (графика, ML, рендеринг).
- **Пропускная способность памяти vs латентность:** CPU оптимизирован под низкую задержку доступа к памяти (большие кэши), GPU - под высокую пропускную способность (широкая память, много потоков для сокрытия задержек). GPU выгоден там, где много однотипных операций над большими массивами данных.

**3.**
VRAM - память на видеокарте, напрямую подключённая к GPU; ОЗУ — общая память системы для CPU. Отличия: VRAM имеет гораздо более широкую шину и выше пропускную способность (GDDR/HBM против DDR), физически распаяна на плате видеокарты и недоступна CPU напрямую. Делают максимально быстрой, потому что GPU обрабатывает огромные объёмы данных (текстуры, кадры) за миллисекунды — иначе процессор будет простаивать в ожидании данных.

**4.**
SIMT - модель, где одна инструкция выполняется одновременно множеством потоков, но каждый поток может иметь свои данные (и, в отличие от SIMD, свой путь ветвления — с оговорками). GPU группирует потоки в варпы (обычно 32), чтобы одна инструкция управляла сразу группой потоков — это экономит блоки управления и повышает эффективность. При расхождении ветвлений внутри варпа потоки выполняются по очереди — отсюда рекомендация избегать дивергентных ветвлений.

**5.**
Охлаждение нужно, т.к. GPU при работе выделяет много тепла — перегрев снижает частоты и может повредить компоненты. Подсистема питания обеспечивает стабильное напряжение и ток нужной силы. Если охлаждение не справится: GPU начнёт троттлить (снижать частоты), затем возможны артефакты, зависания, аварийное отключение; длительный перегрев сокращает срок службы и может вывести карту из строя.
