| Параметр | HDD | SSD |
|---|---|---|
| **Принцип работы** | Магнитные пластины + движущаяся головка | Флеш-память (NAND), без механики |
| **Скорость чтения/записи** | ~100–200 МБ/с | ~500–7000 МБ/с (SATA/NVMe) |
| **Движущиеся части** | Есть (шпиндель, головка) | Нет |
| **Устойчивость к ударам** | Низкая (боится тряски) | Высокая |
| **Уровень шума** | Слышен (щелчки, гул) | Бесшумный |
| **Цена за 1 ТБ** | Дешевле (~2–3 тыс. ₽) | Дороже (~5–10 тыс. ₽) |
| **Срок службы / ограничения** | Ограничен механикой; боится падений | Ограничен ресурсом записи (TBW); деградирует при перегреве |
| **Пример использования** | Архив, бэкапы, медиатека | ОС, программы, игры, рабочие задачи |

## Определения

1. **DDR** - *Double Data Rate* («двойная скорость передачи»). Тип оперативной памяти, передающий данные дважды за такт (по фронту и спаду сигнала), что удваивает пропускную способность по сравнению с SDR.

2. **DIMM** - *Dual In-line Memory Module*. Модуль оперативной памяти с контактами на обеих сторонах платы; стандартный форм-фактор для настольных ПК.

3. **Ранг** - группа чипов памяти на модуле, работающих как единое целое (обычно 64 бита). Модуль может быть одно-, двух- или четырёхранговым; влияет на совместимость и нагрузку на контроллер.

4. **CAS Latency (CL)** - задержка между запросом на чтение и выдачей данных (в тактах). Показывает, сколько тактов ждать ответа; меньше - быстрее.

5. **Тайминги** - набор задержек (CL, tRCD, tRP, tRAS и др.), описывающих время выполнения операций в памяти. Меньшие значения = быстрее, но менее стабильно.

6. **Двухканальный режим** - работа двух модулей памяти параллельно, что удваивает пропускную способность шины. Нужен для роста производительности (особенно в играх и при работе с графикой).
